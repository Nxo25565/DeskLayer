# DeskLayer - Better? shortcut manager
基于electron的快捷方式管理器，可以快捷（或者以文件夹形式）添加、删除、并快速打开常用快捷方式。

## 功能
- [x] 设置内添加快捷方式,文件夹形式添加
- [x] Alt+S 打开快捷方式启动窗口，输入快捷方式简称并回车即可打开
- [x] 自定义主题文件(外部css+js)
- [ ] 窗口大小，快捷键设置，拼音检索宽松
- [ ] 设置内切换主题
- [ ] 使用频率统计，优先排列常用快捷方式
- [ ] 降低资源占用*RAM 400MB+-*

### Project Setup 项目设置

#### Install 安装依赖

```bash
$ npm install
```


#### Build 构建项目

```bash
# For windows 构建windows版本
$ npm run build:win

# For macOS 构建macOS版本
$ npm run build:mac

# For Linux 构建Linux版本
$ npm run build:linux
```
